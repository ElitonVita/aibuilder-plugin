# Screenshots guide / Guia de screenshots

**English: capture real in-game shots with shaders — not AI renders.** Fake renders are dishonest and players notice; real gameplay sells. Shaders (Complementary Reimagined or BSL) + a light resource pack make the same builds look premium without lying about what the plugin does. Say in the description that shaders are only for the photos, not required.

Setup:
- Render distance 12–16 chunks, FOV 60–70, clear weather, midday sun (warm light, long soft shadows).
- Capture at 1920×1080 or higher (F2 saves to `screenshots/`). Hide the HUD (F1), never show the debug screen (F3).
- Turn off any overlay/mod HUD not part of the plugin.

Shots (Modrinth: upload 4; Spigot: same set):
1. **Hero:** finished build with the builder NPC inside the frame, golden-hour light, slight low angle.
2. **Building in progress:** NPC mid-placement, selection area outline visible, materials in hand.
3. **Menu/UI:** the clickable `/builder` menu open in game.
4. **Scale:** one big pack monument (Colosseum/Himeji) for grandeur.
Optional: a 3–5 s GIF loop of a build timelapse (≤10 fps, <5 MB) — Modrinth loops it nicely.

Avoid: AI-generated "gameplay", over-saturated color grading, tiny thumbnails, watermarks.

**Português: capture screenshots reais no jogo, com shaders — não renders de IA.** Renders falsos são desonestos e os jogadores percebem; gameplay real vende. Shaders (Complementary Reimagined ou BSL) + uma resource pack leve fazem as mesmas construções parecerem premium sem mentir sobre o que o plugin faz. Avise na descrição que os shaders são só para as fotos, não obrigatórios.

Setup:
- Render distance 12–16 chunks, FOV 60–70, tempo limpo, sol do meio-dia (luz quente, sombras longas e suaves).
- Capture em 1920×1080 ou maior (F2 salva em `screenshots/`). Esconda o HUD (F1), nunca mostre a tela de debug (F3).
- Desligue qualquer overlay/HUD que não seja do plugin.

Fotos (Modrinth: 4; Spigot: o mesmo conjunto):
1. **Hero:** construção pronta com o builder NPC dentro do quadro, luz dourada, ângulo levemente baixo.
2. **Em obra:** NPC no meio do posicionamento, outline da área visível, materiais na mão.
3. **Menu/UI:** o menu clicável de `/builder` aberto no jogo.
4. **Escala:** um monumento grande dos pacotes (Coliseu/Himeji).
Opcional: GIF de 3–5 s em loop de timelapse de construção (≤10 fps, <5 MB) — a Modrinth faz loop bem.

Evite: "gameplay" gerado por IA, saturação excessiva, miniaturas minúsculas, marcas d'água.
